# Глоссарий проекта «Домашняя AI-станция» (аппаратная часть)

Версия документа: 0.1

Термины аппаратной платформы стенда (Orange Pi CM4, SoC Rockchip RK3566).
Термины и сокращения Системы — в [docs/srs-ru.md](./srs-ru.md)

## 1. Глоссарий

- BootROM (Bootstrap ROM, Boot Read-Only Memory, ROM code) — неизменяемый код начальной загрузки, записанный в постоянную память (Read-Only Memory) процессора. Сразу при подаче питания процессор начинает выполнять этот код. Микропрограмму BootROM записывает производитель чипа;
- BSP (Board Support Package) – пакет программного обеспечения, включающий ядро, драйверы и конфигурации для конкретной платы, обычно предоставляемый производителем чипа;
- Device Tree - описание аппаратной конфигурации Linux;
- DRAM (Dynamic RAM) - внешняя динамическая оперативная память (например, DDR4, LPDDR4X), требующая сложной инициализации контроллера памяти;
- Embedded Linux - концепция дистрибутива для управления устройствами. Обычно включает: загрузчик, ядро Linux, корневую файловую систему, утилиты, библиотеки, службы;
- eMMC (Embedded MultiMediaCard) – встроенная флеш-память для хранения системы и данных (8 ГБ на модуле CM4);
- GPIO - (General-Purpose Input/Output) - интерфейс ввода/вывода общего назначения;
- Idbloader - предзагрузчик Rockchip, содержащий DDR init + SPL/TPL;
- LBA (Logical Block Addressing) — способ адресации блоков на диске или SD-карте;
- M.2 M-Key – разъём на базовой плате, поддерживающий NVMe (через PCIe x1) или SATA-накопители;
- Mask ROM - тип постоянной памяти, содержимое которой создается на этапе производства микросхемы с помощью фотошаблона (маски). Физически невозможно изменить после изготовления;
- Mask ROM Mode - аварийный режим BootROM загрузки. BootRom переходит в этот режим, если не может найти корректный загрузчик ни на одном из носителей. В этом режиме чип ожидает команды от хоста по USB;
- NPU (Neural Processing Unit) – аппаратный ускоритель для операций машинного обучения
- PCIe (Peripheral Component Interconnect Express) – интерфейс для подключения скоростной периферии
- Rockusb - USB-протокол Rockchip для загрузки/прошивки; используется для низкоуровневого взаимодействия с BootRom (в MaskRom-режиме) и загрузчиками для прошивки и восстановления устройств;
- SATA (Serial ATA) – интерфейс для подключения накопителей;
- SDMMC - интерфейс SD-карт/MMC;
- Secure Boot - цепочка доверенной загрузки с проверкой подписи;
- SoC (System on Chip) - микросхема, интегрирующая процессор, графику, контроллеры памяти и периферийные интерфейсы на одном кристалле;
- SoM (System-on-a-Module, SoM) — архитектура компьютерной системы, при которой на одной печатной плате располагаются все необходимые для работы подсистемы;
- SPL (Secondary Program Loader) - вторичный загрузчик; код в ПЗУ загружает SPL в SRAM (небольшая область статической памяти); SPL настраивает контроллер памяти и др. части системы; SPL переходит на начало TPL (третичный загрузчик) - например, u-boot.bin, загружает TPL в DRAM;
- SRAM (Static RAM) - внутренняя статическая оперативная память чипа, доступная сразу после подачи питания. BootRom использует ее как временное хранилище для стека и выполнения кода до инициализации основной DRAM;
- TPL (Third stage program loader) - третичный загрузчик; загружает ядро операционной системы в SDRAM;
- UART - (Universal Asynchronous Receiver-Transmitter) - протокол передачи данных. Например, RS-232;
- U-Boot - начальный загрузчик ядра операционной системы;
