# Одноплатный компьютер Orange Pi CM4 (RK3566) — справочник по аппаратной части

Версия документа: 0.1

Назначение: справочная информация по аппаратной платформе стенда — базовой плате Orange Pi, модулю CM4 (SoM) и SoC Rockchip RK3566.
Требования к Системе — в [docs/srs-ru.md](./srs-ru.md)

## 1. Глоссарий

- eDP (Embedded DisplayPort) – интерфейс для внутренних дисплеев, выведен на дополнительные контакты модуля CM4, но не на базовую плату;
- MIPI DSI (Display Serial Interface) – скоростной интерфейс для подключения дисплеев; на RK3566 доступны 4 линии, но базовая плата разводит только 2
- MIPI CSI (Camera Serial Interface) – интерфейс для подключения камер, аналогично DSI, на базовой плате выведено 2 линии
- PMIC (Power Management Integrated Circuit) – микросхема управления питанием, на модуле CM4 используется RK809-5
- TRM (Technical Reference Manual) – техническое руководство по процессору, содержащее детальное описание регистров, блоков и программирования
- VPU (Video Processing Unit) – блок для ускорения кодирования и декодирования видео; в RK3566: декодирование до 4K@60fps (H.265/H.264/VP9), кодирование до 1080p@60fps

## 2. Спецификация

### 2.1. Базовая плата Orange (Base Board)
| Компонент      | Характеристика |
|----------------|----------------|
| **Видеовыходы**| 1× Micro HDMI 2.0 (4K@60fps), 1× MIPI DSI (2 линии) |
| **Камера** | 2× MIPI CSI (2 линии каждый) |
| **Сеть** | 1× Gigabit Ethernet (RJ45) |
| **USB** | 1× USB 3.0 Host, 2× USB 2.0 Host, 1× USB 2.0 OTG |
| **Хранилище** | Слот MicroSD (TF), разъём M.2 M-Key (SATA3 или PCIe 2.0 ×1 NVMe) |
| **Аудио** | 3.5 мм комбинированный разъём (вход/выход) |
| **Расширение** | 40-контактная колодка (GPIO, UART, I2C, SPI, PWM); напряжение 1.8 В или 3.3 В (переключается джампером) |
| **Охлаждение** | 4-контактный разъём для вентилятора (5 В) |
| **Кнопки** | MASKROM, RECOVERY, RESET |
| **Питание** | USB Type-C, 5 В / 3 А |
| **Размеры (PCB)** | 85 × 56 мм |
| **Масса** | 46 г |

### 2.2. Модуль Orange Pi CM4 (SoM)
| Компонент | Характеристика |
|-----------|----------------|
| **SoC** | Rockchip RK3566 |
| **Оперативная память**  | 2 ГБ LPDDR4 |
| **Встроенная память**   | 8 ГБ eMMC |
| **Беспроводная связь**  | Wi-Fi 5 (802.11ac), Bluetooth 5.0 (чип AP6256) |
| **Ethernet PHY** | YT8531C (10/100/1000 Мбит/с) на модуле |
| **PMIC** | Rockchip RK809-5 |
| **Размеры (PCB)** | 55 × 40 мм |
| **Разъёмы** | 2× 100-контактных + 1× 24-контактный (совместимость с Raspberry Pi CM4 по основным сигналам) |
| **Выведенные сигналы**  | HDMI 2.0, MIPI DSI (4 линии), MIPI CSI (4 линии), eDP, SATA3/PCIe, USB 3.0, USB 2.0 (×3), аудио, GPIO|
| **Операционная система** | Linux (4.19.232) — стоковый BSP-образ вендора; целевая ОС проекта — ALT Linux, ядро 6.18 (SRS НФ-10.1) |

### 2.3. Чип: Rockchip RK3566

### 2.3.1. Общие сведения
| Параметр | Значение |
|----------|----------|
| **Модель** | Rockchip RK3566 |
| **Тип** | Система на кристалле (SoC) для мультимедийных и IoT-приложений |
| **Техпроцесс** | 22 нм |
| **Корпус** | BGA-565 (15.5 × 14.4 мм) |

### 2.3.2. Центральный процессор (CPU)
| Параметр | Значение |
|----------|----------|
| **Архитектура** | ARMv8-A (64-bit) |
| **Ядра** | 4 × Cortex-A55 |
| **Максимальная частота** | 1.8 ГГц |

### 2.3.3. Графический процессор (GPU)
| Параметр | Значение |
|----------|----------|
| **Модель** | ARM Mali-G52 2EE |
| **API** | OpenGL ES 1.1/2.0/3.2, OpenCL 2.0, Vulkan 1.1 |
| **2D-ускорение** | Встроенный аппаратный 2D-ускоритель |

### 2.3.4. Видеопроцессор (VPU)
| Параметр | Значение |
|----------|----------|
| **Декодирование** | 4K@60fps (H.265/HEVC, H.264, VP9) |
| **Кодирование** | 1080p@60fps (H.265/H.264) |

### 2.3.5. Нейронный процессор (NPU)
| Параметр | Значение |
|----------|----------|
| **Модель** | RKNN NPU |
| **Производительность** | 0.8 TOPS (INT8) |
| **Поддерживаемые фреймворки** | Caffe, TensorFlow, TFLite, ONNX, PyTorch, Keras, Darknet |

### 2.3.6. Интерфейсы памяти и хранения
| Параметр | Значение |
|----------|----------|
| **Оперативная память** | DDR3/DDR3L/DDR4, LPDDR3/LPDDR4/LPDDR4X (до 8 ГБ) |
| **Хранилище** | eMMC 5.1, SATA 3.0, SPI NOR/NAND Flash |

### 2.3.7. Высокоскоростные интерфейсы
| Интерфейс | Характеристика |
|-----------|----------------|
| **Дисплей** | HDMI 2.0a (4K@60), MIPI DSI (4 линии), eDP 1.3, RGB/LVDS; поддержка двух независимых дисплеев |
| **Камера** | MIPI CSI (4 линии / 2×2 линии), 8M ISP с HDR |

| **USB** | 1× USB 3.0 Host, 2× USB 2.0 Host, 1× USB 2.0 OTG |
| **Ethernet** | 1× Gigabit Ethernet (GMAC) |
| **Аудио** | 8-канальный I2S/TDM, 2× 2-канальный I2S, 8-канальный PDM, S/PDIF выход |

### 2.3.8. Программная поддержка (со стороны чипа)
| ОС | Примечание |
|----|------------|
| Android 11 | Официальный BSP от Rockchip |
| Linux (ядро 5.10 / 6.1) | BSP-ядро Rockchip с полной поддержкой NPU/VPU. Например, Linux 5.10.160-rockchip-rk356x под архитектуру arm64|
| Linux (mainline 6.6+) | Частичная поддержка (GPU — Panfrost; VPU/NPU — ограничены) |

## 3. Распиновка 40-контактной колодки (GPIO)

### 3.1. Пины SPI и сопутствующие

- 3 : GPIO4 B4 I2C2 SDA
- 5 : GPIO4 B5 I2C2 SCL

- 8  : UART2 TX
- 10 : UART2 RX

- 13 : GPIO 4 A0
- 15 : GPIO 4 A2
- 16 : GPIO 4 A3
- 18 : GPIO 4 A1
- 22 : GPIO 4 A4

- 19 : SPI3 MOSI 
- 21 : SPI3 MISO
- 23 : SPI3 CLK

- 24 : GPIO4 A6 / SPI3_CS0
- 26 : GPIO4_A7 / SPI3_CS1

- GND: 6, 9, 14, 20, 30, 34, 35, 39
- VCC: 1, 17
