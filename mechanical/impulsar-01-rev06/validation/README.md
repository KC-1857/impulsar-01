# Проверка корпуса Импульсар-01 rev06

Проверено 28 сентября 2026 года на ALT Linux, Python 3.14.7, FreeCAD 1.1.3.
Версии Python-зависимостей закреплены в [requirements.txt](../requirements.txt).
Сборка STL повторена в отдельном виртуальном окружении из этих зависимостей.
Самодостаточность дополнительно проверена на копии только каталога варианта
вне репозитория: пересборка STL, пробников и многоцветного 3MF, извлечение сечений,
проверка исходников и повторное открытие готовых FCStd/STEP прошли успешно.
Входные данные находятся внутри варианта, результаты создаются в его `build/`.

## Результаты

| Проверка | Результат |
| --- | --- |
| Целостность готового комплекта | Все 44 файла соответствуют контрольным суммам rev06 |
| Сохранность базовых моделей | Два STL из `source/` соответствуют контрольным суммам в `reference/source.sha256.json`; лазерные DXF входят в контрольный комплект |
| Производственные сетки | 22 STL замкнуты, согласованно ориентированы и однокомпонентны |
| Автономная пересборка STL | Симметрическая разность с исходником менее 0,01 мм³ для каждой из восьми деталей |
| Сопряжения и дискретные траектории | 215 проверок пройдено для пересобранных STL и для экспортов CAD |
| Нативная CAD | Восемь деталей — валидные одиночные твёрдые тела; документ повторно открыт |
| STEP | Повторный импорт восьми деталей и сборки из восьми тел успешен; разница объёма каждой детали менее 0,001 мм³ |
| Редактирование FreeCAD | Изменены все пять размеров таблицы; после пересчёта все восемь деталей валидны и их объёмы изменились |

Разность CAD и исходного STL измерена как объём симметрической разности двух
твёрдых тел, а не просто разность их суммарных объёмов:

| Деталь | Разность, мм³ | Доля объёма исходника |
| --- | ---: | ---: |
| Основание | 4,857333 | 0,007623 % |
| Крышка | 0,323615 | 0,000757 % |
| Планка | 0,035417 | 0,003137 % |
| Каждая из пяти панелей | 0 | 0 % |

Круглые элементы нативной CAD аналитические, исходные STL полигональные;
представления не объявляются побайтно или геометрически идентичными.
Исходные производственные сетки сохранены в `../print/`, экспорты CAD — в `../cad/print/`.

Проверка редактирования использовала толщину акрила 2,80 мм, ширину паза 3,05 мм,
радиусы проходного отверстия 1,75 мм, направляющего отверстия самореза 0,95 мм
и отверстия планки 1,35 мм. Проверялась перестраиваемость дерева, а не пригодность
этого сочетания размеров для изготовления. Изменения не сохранены в готовом FCStd.

## Машиночитаемые отчёты

- [assets-verification.json](assets-verification.json) — контрольные суммы, базовые модели, сетки, многоцветный 3MF.
- [mesh-comparison.json](mesh-comparison.json) — пересобранная сеточная геометрия и исходник.
- [mesh-verification.json](mesh-verification.json) — сопряжения, траектории и намеренные натяги.
- [cad-construction.json](cad-construction.json) — валидность CAD-деталей и огибающих крепежа.
- [cad-verification.json](cad-verification.json) — STEP, сравнение, сопряжения, пересчёт параметров.
- [cad.sha256.json](cad.sha256.json) — контрольные суммы подготовленных CAD-файлов.

Команды повторения приведены в [README](../README.md). Отчёты здесь относятся к
подготовленному комплекту; результаты новых запусков записываются в игнорируемый
`build/`. Контрольные суммы и параметры базового комплекта лежат в `../reference/`.

**Физическая приёмка не выполнена.** Цифровые проверки не подтверждают посадку
реальных плат, лазерный керф, усадку печати, температурный режим или стойкость
к падению. Начинать изготовление следует с пробников из [инструкции](../MANUFACTURING.md).
