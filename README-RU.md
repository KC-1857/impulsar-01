# Impulsar-01 — Домашняя AI-станция

[![Status: Early development](https://img.shields.io/badge/Status-Early%20development-orange.svg)]()

[English version](README.md)

Открытая домашняя AI-станция: голосовой помощник и управление умным домом на базе одноплатного компьютера.

![Прототип](docs/images/Prototipe.png)

## Возможности

- Локальное распознавание русской речи в реальном времени
- Голосовое управление Zigbee-устройствами по фиксированному словарю команд
- Светодиодная индикация состояния (слушаю, команда, готово, ошибка)
- Журнал событий для мониторинга и диагностики

## Аппаратная платформа

- Одноплатный компьютер Orange Pi CM4 (Rockchip RK3566)
- Плата микрофона
- USB-координатор Zigbee
