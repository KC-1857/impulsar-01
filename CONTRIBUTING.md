1. How to Make a Commit and Submit a Pull Request

    Fork the repository (click the Fork button on GitHub).

    Clone your fork:
    git clone https://github.com/your-username/navis-home.git

    Create a branch for your changes:
    git checkout -b feature/feature-name

    Make changes to the code.

    Add the files and commit:
    git add .
    git commit -m "Short description of changes"

    Push the branch to your fork:
    git push origin feature/feature-name

    On GitHub, a Compare & pull request button will appear in your fork — click it.

    Describe what was done and why, and reference any related issues.

    Submit the PR. Wait for CI checks and review from maintainers. If needed, make additional changes in the same branch — the PR will update automatically.

2. How to Contact the Team

    Tasks and bugs — open an Issue in the repository.

    Ideas and discussions — post in GitHub Discussions.

    Quick questions — join the community chat (link will be added later).

    Regarding a specific PR or Issue — leave comments directly there.
